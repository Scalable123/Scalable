# T005 — Hosted Wikimedia API routing

## Outcome

Integrated the Wikimedia endpoint into `Scalable.Api`, the ASP.NET host already used by the deployed GraphQL/Identity service. GitHub Pages remains static, while the browser now targets `SCALABLE_API_ORIGIN` or the configured Render API origin for Wikimedia and Unsplash requests.

## Deployment requirements

- Deploy the updated `Scalable.Api` image/service.
- Allow the exact Pages origin (`https://scalable123.github.io`) through API CORS.
- Persist the API data directory or set `Wikimedia__BudgetPath` to persistent storage so the shared budget survives restarts.
- Set `Wikimedia__UserAgent` to a meaningful contact-bearing value if the default repository URL is not suitable.
- No Wikimedia API key is required. Unsplash remains separately optional and still requires its server-side key.

The repository contains the API and Pages configuration changes, but no Render credentials or production deployment token was available in this workspace; pushing the branch/main can trigger the connected deployment if that service is configured for automatic deploys.
