# T007 — Remove Unsplash integration

## Outcome

Removed Unsplash from the active application. The standalone backend no longer exposes `/api/image-sources/unsplash`, the Unsplash provider/client and browser harness were removed, board research no longer calls or preserves Unsplash items, and the Unsplash status/error message path was removed. Wikimedia Commons remains the active external image source.

## Decisions

- Local sample images remain unchanged and continue to provide the fallback board.
- Wikimedia attribution, multi-image search, AI reference analysis, palette preservation, and generated-image separation remain intact.
- Historical Unsplash task/integration records remain in `docs/` but are explicitly marked retired for auditability; they are not active configuration or implementation.
- Unsplash environment variables, active documentation claims, CSS selectors, endpoint tests, and provider-specific UI copy were removed.

## Verification

- `dotnet build backend/Scalable.Api.csproj --no-restore` validates the remaining standalone Wikimedia host.
- `dotnet build Scalable.Api/Scalable.Api.csproj --no-restore` was attempted; stale generated `Scalable.Api/work` artifacts from earlier verification runs block this check, unrelated to this change.
- `dotnet run --project tests/backend/Scalable.Api.Checks.csproj --no-restore` validates request budgets and Wikimedia fixtures.
- `node tests/ai-reference.node.cjs` and `node tests/wikimedia-source.node.mjs` validate the affected AI/Wikimedia flows.
- JavaScript syntax checks passed for the affected application modules.
- `rg -n -i "unsplash"` should return only historical retired documentation, not active source/configuration/test code.
